# بوت Telegram لإدارة صور الملف الشخصي

مستودع `Mdkdkdjjdjdjd` يحتوي على بوت خاص بـTelegram يجمع بين واجهة تحكم عبر بوت Telegram وعميل مستخدم يستند إلى Telethon. يتيح المصدر البحث عن الصور عبر Pixabay وWikimedia Commons، ثم تنزيل الصور ورفعها كصور ملف شخصي لحساب Telegram الذي يربطه المشغّل. يمكن للمشغّل اختيار الصور يدويًا أو استخدام مسار تلقائي يعتمد على استعلامات البحث.

> هذه الوثيقة مبنية على قراءة ساكنة للملفات. لم يُشغّل المشروع أو تُثبّت اعتمادياته أو تُجرّب خطوات الإعداد والتشغيل؛ لذا لا تمثل ضمانًا لصحة التشغيل أو الجاهزية الإنتاجية.

## ما يوجد في المستودع

- `main_fixed.py` — تطبيق البوت، معالجة الأوامر والوسائط، البحث والتنزيل، وربط حساب Telegram عبر Telethon.
- `requirements-1.txt` — قائمة الاعتماديات المباشرة المثبتة الإصدارات.

لم يُعثر على README سابق في النسخة المفحوصة.

## الميزات الظاهرة في المصدر

- واجهة بوت Telegram تتضمن مسارات للبدء، وإلغاء العملية، وعرض الحالة أو المعرّف، واختيار الوضع اليدوي أو التلقائي.
- تدفق لربط حساب Telegram: يتعامل مع رقم الهاتف ورمز الدخول، وقد يطلب كلمة مرور التحقق بخطوتين إن تطلب الحساب ذلك.
- البحث عن صور عبر Pixabay وWikimedia Commons وتنزيلها محليًا قبل رفعها.
- رفع الصور إلى حساب Telegram المرتبط كصور ملف شخصي، مع مسار يتيح اختيار صورة يرسلها المستخدم ومسار بحث تلقائي.
- يذكر الكود حدًا يصل إلى 20 صورة في العملية التلقائية وحدًا أقصى لحجم الصورة قدره 20 ميغابايت؛ هذه حدود كما تظهر في المصدر وليست نتائج اختبار.

## المتطلبات والإعداد

ملف `requirements-1.txt` يحدد الاعتماديات التالية:

- `aiogram==3.22.0`
- `Telethon==1.45.0`
- `aiohttp==3.13.2`

يعتمد المشروع على Python، لكن الملفات المفحوصة لا توثق إصدارًا أدنى أو بيئة تشغيل محددة. تظهر في المصدر أسماء متغيرات إعداد؛ يقرأ بعضها من البيئة، لكن لا توجد آلية خارجية موحدة موثقة لكل متغير:

`BOT_TOKEN`, `API_ID`, `API_HASH`, `PHONE_NUMBER`, `PIXABAY_API_KEY`, `IMAGE_SOURCE`, `SESSION_NAME`, `OWNER_FILE`, `DELAY_BETWEEN_UPLOADS`, `DOWNLOAD_DIR`.

يحتوي المصدر كذلك على قيم اعتماد ثابتة/احتياطية؛ لذلك لا ينبغي تشغيل النسخة كما هي أو نشرها قبل إزالة تلك القيم وإبطال أي بيانات اعتماد سبق تضمينها. لا يحتوي هذا التوثيق على قيم إعداد أو أسرار. تحقق من مسار إعداد كل قيمة واستخدم وسيلة أسرار آمنة حيث يدعمها التطبيق، ولا تشارك ملفات جلسة Telethon أو ملفات المالك أو مجلدات التنزيل.

## خطوات مقترحة (غير مجرّبة)

الأوامر التالية مستنتجة من أسماء الملفات ومن وجود ملف اعتماديات ونقطة دخول Python؛ لم تُنفّذ ولم يُتحقق من نجاحها:

1. راجع المصدر وأزل أي بيانات اعتماد ثابتة، ثم جهّز قيم الإعداد المطلوبة بطريقة آمنة خارج المستودع.
2. أنشئ بيئة Python مناسبة للمشروع.
3. ثبّت الاعتماديات المدرجة في الملف:

   ```bash
   python -m pip install -r requirements-1.txt
   ```

4. بعد مراجعة مخاطر التشغيل وضبط الإعدادات، نقطة الدخول الظاهرة هي:

   ```bash
   python main_fixed.py
   ```

لا توجد تعليمات مؤكدة في الملفات حول النشر، إعداد خدمة دائمة، النسخ الاحتياطي، أو استعادة الجلسات. كما يتضمن المصدر محاولة تثبيت اعتماديات عند الاستيراد؛ ينبغي مراجعة هذا السلوك وإزالته أو ضبطه قبل الاستخدام، بدل الاعتماد على تثبيت تلقائي وقت التشغيل.
